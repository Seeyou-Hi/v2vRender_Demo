# 离线与流式效果差异核查（2026-10-19）

历史基线：`results/krea_case23_ref_20261016/case2`，15 FPS 输入预处理到 16 FPS，共 164 帧；640×384、四步、seed43、bf16_blocks、四卡。当前页面是 5 FPS、两卡、新 ext1 参考图及不同提示词。

复用两卡常驻作业 14489，保持权重、旧参考图、seed、控制帧和分块设置一致，完成以下真实 GPU 对照：

| 对照 | 结果 |
| --- | --- |
| 当前离线入口 164 帧 vs 当前流式入口相同 164 帧 | 离线原始 RGB 数组与流式无损 PNG **逐像素完全相同**，最大误差 0 |

| 同一 5 FPS 深度及参考图，旧场景提示词 vs 当前通用长提示词（含固定规则） | 通用长提示词下左罐红金外观逐渐消退，色垫漂移；旧场景文本保持更好 |

最后一项首次因上传的提示词文件权限 0600 导致 GPU 租户无法读取，在推理前失败；改为可读权限、保留失败目录并用新输出路径重跑成功。

Depth 本身不包含颜色和标签；参考图只在首块传入，后续依靠模型状态延续。明确物体身份的文字条件在本案例中比纯通用外观稳定要求更有效。这里的 FPS 改动包含控制帧下采样，不是仅修改 MP4 时间戳；模型调用未额外传入 FPS 参数。

前端默认文本恢复为旧 case2 原始场景描述，明确双臂、左红金罐、右红瓶、蓝橙垫、参考材质和深度控制。后端几何/运动固定规则保留，前端仍可编辑；更换物品需相应修改场景描述。停止输入并刷新、新建会话后生效，不重启后端。
