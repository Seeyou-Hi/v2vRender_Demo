# ext1 首帧参考图流式渲染

## 使用

1. 先选择机械臂夹爪、物品和仿真设置，结束正在进行的任务。
2. 点击“重置到 ext1 并导出首帧”。该操作退出自动演示、重置场景、选择 ext1，导出 1280×768 PNG；不要求 GPU 后端在线。
3. 用图像编辑模型将该图渲染为真实工业实验室照片：保持相机位置、透视、构图、机器人关节、比例、夹爪形态、物体数量和位置，只改变材质、光照、纹理、阴影和清晰度。输出保持原图尺寸或同为 5:3，不裁剪或拉伸。
4. 选择生成的 PNG/JPEG。前端校验图片可解码、大小不超过 20 MB、比例匹配，并显示参考图预览。
5. 保持“流式渲染使用参考图”勾选，启动流式渲染。前端会再次重置当前配置的场景并选择固定 ext1；请勿在导出后改变物品或夹爪配置。模型需要先启动并常驻就绪。
6. 5 FPS 输入，首块 9 帧、后续 12 帧保持不变。停止时仍需点击“停止流式输入”。不勾选参考图时保留原有相机选择和无参考图流程。离线视频提交不读取本选项。

参考图是 VACE 图像条件，不是硬性首帧替换，也不保证几何完全相同。后续块不重复注入参考图，外观通过自回归状态延续。

## 实现

- `frontend/dist/reference-frame.js`：源图导出、参考图选择及预览。源图使用相同流式 RGB 捕获路径；1280×768 与模型 640×384 的 ext1 归一化投影一致。
- `app.js`：独立 ext1 视图，使用采集相机和 5:3 留边显示；原“正视”预设保留。
- `stream-capture.js`：启用参考图时在开始前重置 ext1，打开会话期间冻结仿真时间，避免上传过程中起始状态前进。
- `backend-render.js`：参考图先上传 PNG/JPEG，再通过 `/streams` 的 `reference` 字段传递文件标识；检查 `health.stream_reference`，旧服务不支持时明确拒绝，不静默丢弃参考图。
- `scripts/server.py`：流式与离线请求均校验参考图文件标识；流式任务现在也传 `--reference`。推理脚本既有首块 `vace_ref_images` 条件保持不变。
